GPU Workers

Theo dõi các GPU worker bạn thuê thủ công từ nhà cung cấp bên ngoài (hiện đang dùng EzyCloudX). Dữ liệu mẫu.

Bạn tự thuê và tự xóa Docker GPU từ nhà cung cấp bên ngoài (hiện đang dùng EzyCloudX, không giới hạn provider) bằng tài khoản của mình. App không tự provision/terminate máy và không dùng API nội bộ của nhà cung cấp — app chỉ nhận worker qua enrollment token và theo dõi heartbeat.

Batch Media Workers

· container render nặng theo job, scheduler tự giao việc

Interactive TTS Workers

· container OmniVoice phản hồi nhanh cho nghe thử/tạo giọng
Batch Media Worker và Interactive TTS Worker là hai container Docker độc lập — mỗi container một vai trò, không có worker nào tự chạy cả hai.

Thêm GPU Worker

Bạn tự thuê máy từ nhà cung cấp GPU rồi chạy lệnh bootstrap bên dưới — app không tự tạo máy.

Enrollment token & lệnh bootstrap

Chạy lệnh này trong máy GPU bạn vừa thuê từ nhà cung cấp — worker sẽ tự đăng ký và bắt đầu gửi heartbeat.

Xác nhận đã xóa rental

Chỉ xác nhận sau khi bạn đã tự Stop và xóa container trên console của nhà cung cấp.
